# Result Status Ledger

Every headline result in this repository falls into exactly one of four states.
This ledger is the single place to check which.

| State | Meaning |
| --- | --- |
| **Computed** | Regenerated from artifacts present in the tree by a builder that fails if its inputs are missing. Reproduce with `python scripts/run_clean_reproduction.py`. |
| **Historical** | A number produced by an earlier run whose inputs are no longer in the tree. Retained, labelled, and never regenerated. Not evidence. |
| **Withdrawn** | The computation was performed but does not support the claim made from it (circular target, oracle-assisted comparison, or invalid inference units). |
| **Awaiting data** | Blocked on labels or experiments that do not exist yet. |
