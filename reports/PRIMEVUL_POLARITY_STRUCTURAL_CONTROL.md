# PrimeVul Polarity Structural Control

Generated by `scripts/evaluate_polarity_structural_control.py`.

This report supplies the missing negative control for the paired-diff
formulation. Each rule below reads **only the shape of the diff** -- how many
lines were added and removed -- and never the content of any line. Signs and
thresholds are fit on the training split; the evaluation split is untouched.

The three original negative controls (metadata-only, candidate-only,
counterpart-only) all *remove* the diff, so none of them can test whether diff
structure alone solves the task. These rules retain the structure and remove
the semantics, which is the complementary control.

### Rule definitions

- `added_lines`: added-line count alone
- `added_minus_two_removed`: asymmetric combination of added and removed counts
- `char_direction`: sign of the net character change only
- `char_net_over_total`: net character change normalised by total character change
- `char_polarity`: net added-minus-removed CHARACTER count (strongest known semantics-free rule)
- `diff_direction`: sign of the net line change only (loses magnitude)
- `indent_polarity`: net added-minus-removed leading-whitespace count (formatting signal only)
- `net_over_total`: net change normalised by total change (combination)
- `net_polarity`: net added-minus-removed line count
- `removed_chars`: removed-character count alone
- `removed_lines`: removed-line count alone
- `total_changed_chars`: total changed-character count (size only, no direction)
- `total_changed_lines`: total changed-line count (size only, no direction)
