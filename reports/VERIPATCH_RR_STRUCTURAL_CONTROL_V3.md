# VeriPatch-RR Structural Control on the Repaired (v3) Suite

Generated by `scripts/evaluate_veripatch_rr_structural_control_v3.py`.
Artifact: `reports/veripatch_rr_structural_control_v3.json`.

This supersedes the numbers in
[VERIPATCH_RR_STRUCTURAL_CONTROL.md](VERIPATCH_RR_STRUCTURAL_CONTROL.md), which
ran on a suite where 100% of DeltaSecommits rows were malformed by a source
newline defect. That report and all v1 artifacts are retained untouched as the
record of the contaminated state.

## What changed

| | v1 (contaminated) | v3 (repaired) |
| --- | --- | --- |
| DeltaSecommits ingestion | single-line `code`, no line structure | `normalize_code_for_diff` applied to `code` |
| Exact swap mirror, representative suite | 375/600 (`0.6250`) | **600/600** |
| Construction invariant | none | `swap_mirror_is_exact` enforced at load |

New inference: `scripts/predict_veripatch_rr.py`, both checkpoints, v3
renderings, batch size 4, max length 1024,
`transformation_introduced_critical_truncation_rows: 0` for all variants.

**Derivation control.** The antisymmetric-inference decision
(`s = logit P(B|canonical) − logit P(B|side_swap)`) was re-derived by this
script on the *v1* artifacts and reproduces the published
`REPAIR_ANTISYMMETRIC_RESULT_V1.md` value of `0.7333` exactly, so the v3 numbers
come from a validated code path.

## The DeltaSecommits result reverses

DeltaSecommits was the only source where the antisymmetric repair beat the
control, and it was the source that was 100% malformed:

| | control | repaired antisym | delta |
| --- | ---: | ---: | ---: |
| v1 (contaminated) | `0.0000` | `0.6000` | `+0.6000` |
| **v3 (repaired)** | **`0.8700`** | `0.8200` | **`-0.0500`** |

The `+0.6000` was the rendering defect, not a capability. On the corrected
rendering the control is ahead. This was the one unresolved row in
`docs/ARC2_REVISED_MAIN_LINE.md`; it is now resolved against the repair.

## The fine-tuning increment is exactly zero on clean data

`REPAIR_ANTISYMMETRIC_RESULT_V1.md` reported that fine-tuning added `+0.0267`
over the projection null in-distribution (21 fixed, 5 broken, McNemar
`p = 0.002`), while failing to transfer to CrossVul and to five nuisance
families. On the repaired suite that in-distribution increment disappears:

| Suite | fixed | broken | delta | exact McNemar |
| --- | ---: | ---: | ---: | ---: |
| v1 (contaminated) | 21 | 5 | `+0.0267` | `p=0.002` |
| **v3 (repaired)** | **6** | **6** | **`+0.0000`** | **`p=1.0`** |

This is not a code artifact: the two checkpoints produce different raw
probabilities on 1,799 of 1,800 rows, and their antisymmetric decisions differ on
12 of 600 pairs. The disagreements simply split evenly.

So the fine-tuned antisymmetric objective now has **no** surviving evidence of
effect: not in-distribution, not on an external source, not across nuisance
transforms.

## What the antisymmetric readout still does

The projection null remains a real structural property: equivariance is exact by
construction (600/600 pairs flip), and it lifts both-directions-correct far above
independent inference (`0.8117` vs `0.6383` pooled). That is a genuine
architectural result and is unaffected by this report.

What it does not do is exceed a semantics-free character-counting rule, which
reaches `0.9867` equivariance and `0.8383` both-directions-correct on the same
pairs without a model.

## Verdict

1. On a benchmark where every pair renders a valid side swap, no system in this
   repository outperforms `char_polarity` on any source or metric.
2. The repair's only previous win was an artifact of a corrupted source and
   reverses once that source is fixed.
3. The fine-tuning increment over the projection null is `+0.0000`
   (`p = 1.0`) on clean in-distribution data.
4. The antisymmetric readout's exactness and its gain over independent inference
   are unaffected and remain valid.

## Claim boundary

One control rule, one fitted threshold, three sources, 600 pairs, two
checkpoints, one length (1024), one seed. This does not establish that no
learned model can exceed diff-shape structure — it establishes that neither
checkpoint in this repository does, on this suite.
